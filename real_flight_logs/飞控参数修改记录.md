# 飞控参数修改记录

> PX4 v1.17.0 / CUAV 7-Nano / 2026-07-23 真机飞行后调整

---

## 修改一览

| 参数 | 原值 | 新值 | 对应问题 |
|------|------|------|----------|
| `COM_RC_IN_MODE` | 3 (MavLink Only) | 0 (RC Only) | ① 遥控器上锁仍可解锁 |
| `COM_DISARM_LAND` | 2.0 | 0.5 | ③ 落地后电机怠速太久 |
| `LNDMC_TRIG_TIME` | 1.0 | 0.8 | ③ 落地检测延迟 |
| `LNDMC_XY_VEL_MAX` | 1.5 | 1.2 | ③ 落地时水平速度要求 |
| `MPC_TKO_SPEED` | 0.6 | 1.2 | ② 起飞爬升过慢 |
| `MPC_TKO_RAMP_T` | 3.0 | 2.0 | ② 起飞 ramp 过长 |
| `MPC_XY_VEL_MAX` | 12.0 | 8.0 | ② 水平速度上限过高 |
| `MPC_XY_VEL_P_ACC` | 1.8 | 1.2 | ② 水平加速度前馈过大 |
| `MPC_Z_VEL_MAX_UP` | 1.0 | 1.2 | ② 最大爬升率 |

---

## 逐项说明

### `COM_RC_IN_MODE: 3 → 0`

**问题**：遥控器 Arm Switch 在 Disarm 位时，代码仍可直接解锁起飞。

**原因**：原值 3 是 "MavLink Only" 模式，PX4 将 RC 状态解释权完全交给 Companion Computer。但上位机代码从未上报 RC 状态，PX4 默认认为 RC OK，不检查 arm switch。

**改为 0 (RC Only)**：PX4 自行检查 RC 信号有效性。遥控器 Arm Switch 在 Disarm 位 → 飞控拒绝一切解锁请求。日志中 `manual_control_signal_lost=1` 会在 RC 未连接时触发 failsafe。

**注意**：飞行前必须确保遥控器开机、接收机对频，否则飞控拒绝解锁。

---

### `COM_DISARM_LAND: 2.0 → 0.5`

**问题**：落地后 `landed=1` 到 disarm 间隔 2.2 秒，电机以 ~1140 PWM 怠速旋转，螺旋桨持续缓慢转动。

**日志证据**：
```
63.9s  landed=1   motors=[1259, 1176, 1264, 1227]  ← 检测到落地
66.1s  armed=0    motors=[1000, 1000, 1000, 1000]  ← 2.2s 后才停转
```

**效果**：落地确认后 0.5 秒自动上锁，螺旋桨几乎立即停转。

---

### `LNDMC_TRIG_TIME: 1.0 → 0.8`

**问题**：PX4 land detector 的 ground_contact 等条件满足后，仍需持续 1 秒才最终确认 `landed=1`。

**效果**：缩短 0.2s 的确认等待。0.8s 足以过滤触地反弹，不会误触发。

---

### `LNDMC_XY_VEL_MAX: 1.5 → 1.2`

**问题**：着陆检测要求水平速度低于此值。原值 1.5 m/s 偏宽松。

**效果**：着陆时水平漂移 > 1.2 m/s 时 land detector 不会触发。现有 landing 代码以 0 m/s 水平速度下降，不受影响。

---

### `MPC_TKO_SPEED: 0.6 → 1.2`

**问题**：起飞爬升 5m 花了 15 秒（理论 8.3s + ramp 3s = 11.3s），过慢的爬升延长了低空危险窗口。

**日志证据**：
```
 7.4s  实际 Z=-0.35m (仅 35cm 高)
14.9s  实际 Z=-4.95m (终于到 5m)
```

**效果**：5m 爬升约 4-5 秒（含 ramp），减少低空滞留时间。

---

### `MPC_TKO_RAMP_T: 3.0 → 2.0`

**问题**：起飞 setpoint 从 0 到目标高度用 3 秒 ramp 平滑，前 3 秒 Z 误差一直很大，无人机在极低高度积累积分。

**效果**：2 秒进入全速爬升，配合 `MPC_TKO_SPEED=1.2`。

---

### `MPC_XY_VEL_MAX: 12.0 → 8.0`

**问题**：水平速度上限 12 m/s（43 km/h）远超任务需求（巡航 2-3 m/s）。起飞时 setpoint 从 (0,0,-5) 跳到 (20,2,-5) 时，20m 位置误差在 12 m/s 上限下导致非常激进的加速。

**效果**：限制控制器追赶 setpoint 时的最大水平输出，起飞阶段的水平冲动更温和。

---

### `MPC_XY_VEL_P_ACC: 1.8 → 1.2`

**问题**：P 加速度前馈增益。1.8 意味着 10m 位置误差产生 18 m/s² 加速度指令（接近 2G），飞控倾斜角过大。

**效果**：同样的位置误差产生约 2/3 的加速度，姿态倾斜减小，起飞更平稳。

---

### `MPC_Z_VEL_MAX_UP: 1.0 → 1.2`

**问题**：最大爬升速度原为 1.0 m/s，配合 `MPC_TKO_SPEED=1.2` 需要提升上限。

**效果**：允许爬升速度达到 1.2 m/s。

---

## 未修改但有影响的参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `CBRK_IO_SAFETY` | 22027 | CUAV 7-Nano 无物理安全开关，必须保持此断路器激活 |
| `LNDMC_Z_VEL_MAX` | 0.25 | 无法修改。代码层改为 0.2 m/s 下降速度以适配 |
| `SYS_HAS_NUM_DIST` | 0 | 无距离传感器，落地检测纯靠 IMU+气压计 |
| `COM_OBL_RC_ACT` | 0 | offboard 丢失后无动作（建议后续改为 2=Land） |

## 配套代码修改

| 文件 | 改动 | 说明 |
|------|------|------|
| `flight_controller.py` | `land()` 下降 0.3→0.2 m/s | 适配 `LNDMC_Z_VEL_MAX=0.25`，下降速度在 land detector 阈值内 |
| `flight_controller.py` | `land()` 用 `force_disarm()` | 落地后直接强制上锁 |
| `flight_controller.py` | `land()` 超时 30→15s | LAND mode fallback 更快 |
| `standalone_bridge.py` | `arm()`/`set_offboard_mode()` 加限流 | 遥测未就绪不发、已 armed/offboard 不重发、1Hz 硬顶 |
