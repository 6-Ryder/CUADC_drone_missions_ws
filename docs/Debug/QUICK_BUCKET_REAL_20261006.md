## 确定的代码缺陷

1. bucket 世界投影后仍用 `max(pose[2] * 1.5, 3.0)` 做水平距离过滤。PX4 垂直坐标原点任意，本次 World z 为负；因此过滤范围被固定为 3 m。使用 jetson 原函数和真实坐标变换做隔离复现：相同物理高度、姿态、像素，仅将垂直坐标原点平移约 7.818 m，距离飞机约 3.394 m 的合法投影从拒绝变为接受。该缺陷确实存在，但缺少本次图像/逐目标数据，尚不能证明它是此次失败的唯一根因。
2. `_current_altitude` 仍直接取 World z，使日志显示负高度，低空蓝盘阈值也无法按实际高度切换。bucket 圆筒半径计算已有地面锚点补偿，不能因此声称半径计算全错。
3. 搜索状态 `exit()` 无条件记录“CYL_SEARCH → SELECT_TARGET”。人工接管同样写出“搜索完成”。退出时计数是原始圆筒记忆库，三个原始圆筒不等于三个合格小桶/桶盘配对。
4. 搜索日志仅在合格候选数量改变时输出，零合格目标时无法区分尺寸证据不足、配对不存在、配对歧义、世界投影无效。
