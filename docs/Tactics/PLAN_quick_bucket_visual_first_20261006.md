# Quick bucket 视觉主导目标选择与伺服

## 目标与边界

桶口世界坐标由高空图像投影得出，误差不能作为搜索、选桶、开始降高或最终对心的否决条件。高空有效坐标只给出粗略接近方向；当前相机图像中的圆筒才决定跟踪和下降。保持 jetson 的硬件、通信、话题、相机方向和实测几何。

## 控制流程

1. 搜索区继续按既有航点到达 4.5 m。bucket 圆筒检测在置信度、像素中心和尺寸有效时入库；用近期不同采集帧及像素连续性建立候选，不要求世界投影有效，也不根据投放区世界矩形拒绝。可用世界坐标只作为粗参考记录。
2. 选择优先 6–9 cm 半径的小桶，其他合理尺寸可进入伺服。若粗坐标无效，选择器仍可选择其视觉候选。选中后用像素连续性锁定圆筒；当前图像可见时只发视觉伺服速度，不用世界航点覆盖它。短时丢帧时停止下降并尝试重捕获。
3. 下降阶段用新鲜圆筒图像计算偏差，沿用真机已验证的画面到机体方向。高空记忆世界坐标不参与身份否决。图像中蓝盘只在当前低空能与圆筒明确关联时作为后舱投放目标。
4. 末段投放预测需要目标相对机体位置时，从低空当前图像、相机内参和同一时刻机体高度换算到局部平面；不使用高空存储的桶口世界坐标做半米身份拒绝。保留新鲜度、唯一性、速度、1.5–1.7 m 高度、刹车、桶径、落点余量和标定锁。`bucket_calibration_valid=false` 仍禁止小桶自动释放。

## 验证

先复现“世界投影无效但圆筒图像稳定仍无法进入伺服”，再覆盖视觉锁定、像素连续、丢帧停止下降，以及低空视觉坐标与高空世界粗坐标冲突时继续按当前图像对心。运行任务包回归与构建，选择性同步 jetson 功能代码。完整命中率仍需真机试投和日志确认。

- 已在 Optimization 复现世界投影无效时搜索停滞的失败用例。bucket 记忆现按像素和跟踪 ID 归并，并只对置信度、半径和不同采集帧做搜索准入。
- 视觉可见时，接近状态用既有真机方向的像素比例伺服；仅短时丢帧且有粗坐标时发送限幅粗靠近航点，无坐标则停住重捕获。进入下降需连续新鲜图像帧。
- 下降与末段门禁从当前圆筒、蓝盘像素及当前机体位姿计算局部相对目标。高空世界投影不参与目标身份和落点拒绝。低空蓝盘唯一关联、标定锁、速度、桶径、落点和释放复核仍生效。
